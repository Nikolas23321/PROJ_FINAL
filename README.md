# Valen — Aluguel de Casas de Praia

## Sobre o projeto

A **Valen** é um projeto de desenvolvimento de um site para uma agência especializada no aluguel de casas de praia. O objetivo é apresentar as opções de hospedagem, suas características e informações importantes para pessoas que desejam aproveitar momentos de lazer no litoral.

O site busca oferecer uma experiência visual agradável, com informações organizadas e navegação simples.

## Objetivos

- Apresentar casas de praia para aluguel.
- Exibir fotos e informações sobre as hospedagens.
- Facilitar a navegação entre as páginas do site.
- Desenvolver uma interface organizada, intuitiva e responsiva.

## Funcionalidades previstas

- Página inicial com apresentação da Valen.
- Página com informações e imagens das casas de praia.
- Página Sobre, com informações sobre a agência.
- Menu de navegação entre as páginas.
- Estrutura de modelos e banco de dados para as informações do sistema.
